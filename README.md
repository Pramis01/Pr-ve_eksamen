# Linux Home Server Project

## Overview
This project is a Linux based home server running on Ubuntu Server 24 LTS in a virtual environment using UTM on macOS.

The purpose of this project is to learn Linux server administration, networking, file sharing, media hosting and system security.

---

## Services Used

- Samba -> File sharing server
- Jellyfin -> Media server
- Apache -> Web server
- SSH -> Remote administration
- UFW -> Firewall protection

---

## Virtual Environment

Host Machine:
- macOS

Virtualization Software:
- UTM

Guest OS:
- Ubuntu Server 24 LTS
